# Кодовая презентация исследования рынков

Текущая клиентская версия — `output/pdf/Market_Launch_Research_v16_2026-09-17.pdf`. Слайды собираются из HTML/CSS в PNG, затем объединяются в PDF с кликабельными ссылками. PowerPoint не используется.

`src/index-v9.html` подключает текущую версию дизайна и контента: `deck-v9.js`, `country-data-v9.js`, `market-presence-v14.js` и `channel-data-v16.js`. Остальные версии в `src/` сохранены как история работы; входной файл `index.html` относится к прежней версии и не должен использоваться для сборки текущего PDF.

`assets/` содержит концептуальные изображения презентации. Они не являются фотографиями продукции будущего бренда. Скриншоты конкурентов находятся в `../../research_assets/reference_screenshots/` и служат исследовательскими референсами.

Сборка описана в [корневом README](../../README.md). Папки `slides/`, `qa/`, `tmp/` и большая часть `output/` содержат воспроизводимые промежуточные файлы и не загружаются в GitHub.
