## P0 — исправить до финального PDF

### Слайд 14 — «План на IV квартал и начало 2027 года»

Проблема: подпись «ОГРАНИЧЕНИЕ» шире выделенной ей колонки на 31 px и перекрывает начало фразы «Решение о масштабе…». Фактическое наложение текста — около 9 × 29 px.

Предпочтительная правка:

```css
.season-warning {
  grid-template-columns: 210px 1.3fr 190px 1fr;
}
```

Более чистая копирайт-правка: заменить «ОГРАНИЧЕНИЕ» на «ВАЖНО». Это лучше читается и не требует расширять колонку.

### Слайд 26 — «Доказательства происхождения»

Проблема: в пятой строке «Использование» слипается с пояснением: визуально получается «Использованиекак предмет…». Фактическое наложение — около 4 × 26 px.

Правка:

```css
.origin-steps > div {
  grid-template-columns: 55px 190px 1fr;
  column-gap: 16px;
}
```

Можно одновременно сократить подпись до «В быту», если смысл останется точным.

### Слайд 2 — «Первый тест: кашемировый шарф по цене €129»

Проблема: строка в правой карточке заканчивается предлогом «по»:

> Проверять в подарочном наборе или по  
> отдельной маркетплейс-модели.

Причина: типографическая функция делает только один проход. Она связывает «или по», но уже не связывает соседнюю пару «по отдельной».

Надёжная кодовая правка: применять `forwardRx` повторно, пока строка перестаёт меняться. Локальная копирайт-правка:

> Проверять как дополнение к подарочному набору. Для маркетплейса считать отдельную экономику.

## P1 — читаемость

### Слайд 41 — «Что готово к обсуждению, а что ждёт Avdar»

- Статусные плашки набраны 13 px — это самый мелкий значимый текст во всей презентации.
- Рекомендуемый минимум — 15–16 px.
- При увеличении шрифта расширить третью колонку строки до 220 px.
- Более прямой заголовок: «Статус десяти результатов».

```css
.deliverable-grid > div { grid-template-columns: 55px 1fr 220px; }
.deliverable-grid em { font-size: 15px; }
```

### Слайд 27 — «Что можно утверждать о товаре»

- Статусы «ИЗМЕРИТЬ / ПОДТВЕРДИТЬ / НЕ ИСПОЛЬЗОВАТЬ» набраны 14 px.
- Поднять `.claim` до 16 px; при необходимости расширить последнюю колонку с 230 до 260 px.
- Нижняя цепочка со стрелками выглядит технически и мелко. Переписать обычной фразой без стрелок.

```css
.claim { font-size: 16px; }
.claims-table th:last-child { width: 260px; }
```

### Слайд 31 — «Пять товарных кандидатов для первой витрины»

- Заголовки таблицы набраны 14 px, вторичные строки цветов — 15 px.
- Поднять заголовки до 16 px, основной текст таблицы до 18 px, цвета минимум до 16 px. Пространства по вертикали достаточно.
- Английские названия цветов выбиваются из русской клиентской версии. Оставить код/официальное имя при необходимости, но добавить русский эквивалент: «шоколадный / 1010», «чёрный / натуральный коричневый», «белый / L», «чёрный».
- В источнике заменить «Gate 0» на «проверка готовности» или «этап 0».

### Слайд 25 — «Что должно быть снято до запуска»

- Номера блоков — 15 px, пояснения — 16 px.
- Подпись «ПЕРЕД ПУБЛИКАЦИЕЙ» выходит из колонки на 19 px; пока не сталкивается с текстом, но зазор остаётся около 5 px.
- Расширить первую колонку нижней строки до 240 px.
- Верхняя подпись со стрелкой выглядит шаблонно. Вместо «Один съёмочный день → несколько форматов» лучше «Материалы на первую съёмочную смену».

```css
.production-rule { grid-template-columns: 240px 1fr auto; }
```

## P1 — контраст мелких подписей

Текущий медный `#b5653e` на молочном `#f1ede4` имеет контраст около 3,67:1. Для крупных цифр это допустимо, для 13–18 px подписей — слабовато, особенно на проекторе.

Не нужно менять цвет крупных плашек. Лучше завести отдельный цвет для мелкого медного текста, например `#a45231` с контрастом около 4,69:1.

```css
:root { --copper-text: #a45231; }
```

Его стоит применить к мелким индексам, подписям таблиц и ссылкам на светлых слайдах.
