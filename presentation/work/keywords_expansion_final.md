# Avdar Market — расширенное приложение по поисковым запросам

**Дата проверки:** 15 сентября 2026 года  
**Рынки:** Германия, Нидерланды, Бельгия (нидерландский и французский), Дания, Швеция, Польша, Финляндия  
**Объём ядра:** 288 локализованных сочетаний: 36 на каждую из восьми языковых групп  
**Отдельный приоритет:** 48 запросов для Германии и Нидерландов  
**Статус:** семантическое ядро для проверки в Google Ads Keyword Planner; не прогноз спроса и не медиаплан

## Что здесь можно и нельзя считать доказанным

- Ядро покрывает все обещанные семейства: кашемировый и шерстяной шарф, носки, перчатки, шаль/палантин, пледы и одеяла, як, верблюжья шерсть, подарок/набор, уход и сравнение материалов.
- Базовые названия категорий и их живое употребление проверены по официальным локальным страницам Google и локальным каталогам брендов/ритейлеров. Составные сочетания с полом, цветом, покупкой, подарком и уходом — рабочие кандидаты, а не утверждение о наличии измеримого спроса.
- Для каждого рынка нужны отдельные настройки страны и языка. Бельгию нельзя объединять в одну кампанию без разделения нидерландского и французского креатива и посадочных страниц.
- **Объём, CPC, конкуренция и верхняя ставка для всех 288 строк: `нужна проверка`.** В этот файл не перенесены неподтверждённые оценки.
- Google Trends даёт относительный нормированный индекс 0–100, а не абсолютное число запросов. Низкочастотные сочетания могут отображаться как 0. Для абсолютных значений нужен экспорт Keyword Planner с зафиксированными location, language, network, date range и match type.
- По действующей справке Google Ads с сентября 2026 года языковое соответствие Search-рекламы в большей степени определяется языком запроса, объявления и посадочной страницы. Перед запуском настройки нужно перепроверить в аккаунте, так как переход происходит сейчас.

## Как использовать ядро

1. Загрузить по одной языковой группе в Keyword Planner, выбрав только Google Search, отдельную страну, соответствующий язык и последние 24–48 месяцев.
2. Экспортировать: keyword, average monthly searches, monthly history, competition, top-of-page bid low/high, location, language, network.
3. Не смешивать exact wording и Topic из Google Trends: это разные объекты измерения.
4. Разнести результаты по страницам: категория, карточка товара, подарочный лендинг, материал/происхождение, уход.
5. Для запуска оставить только релевантные запросы с доступным товаром. Запросы по носкам из яка сейчас являются исследовательскими: в Product Master запас равен нулю.

## Легенда интента и сезонности

| Обозначение | Значение |
|---|---|
| Категория | Пользователь выбирает тип товара; подходит для SEO-категории или поисковой группы объявлений. |
| Покупка | Явное коммерческое намерение: купить, пол, цвет, состав. |
| Подарок | Получатель, комплект или праздничный повод. |
| Информация | Уход, отличие материалов, происхождение. |
| Холодный сезон | Основное окно проверки: конец сентября — январь; фактическую помесячную кривую брать из Planner. |
| Праздники | Ноябрь–декабрь; дополнительные поводы проверять отдельно по рынку. |
| Круглый год / Q4-тест | Материальные и образовательные запросы можно индексировать постоянно, платный тест начинать в сезон. |

## Что проверить в Keyword Planner в первую очередь

1. Все 48 приоритетных запросов — Германия и Нидерланды, отдельно по стране и языку.
2. Сочетания с `100%`, дефисами и составными словами: Planner может объединять close variants; исходный экспорт должен сохраняться.
3. В Нидерландах сравнить `kasjmier sjaal` и `cashmere sjaal`, не предполагая заранее, что один вариант сильнее.
4. В Бельгии запустить два независимых прогона: NL и FR. Не суммировать их до дедупликации.
5. Для шведского отдельно проверить слитные и раздельные варианты: `kashmirhalsduk` / `kashmir halsduk`, `ullhalsduk` / `ull halsduk`.
6. Для редких материалов и подарочных наборов не покупать трафик, если Planner и фактическая выдача не подтверждают коммерческий интент.
7. Негативные слова для первичной чистки: выкройки, пряжа, вязание своими руками, опт (если B2C), бесплатно, б/у, ремонт, работа, вакансии. Перевести и подтвердить по реальному search terms report после старта.
